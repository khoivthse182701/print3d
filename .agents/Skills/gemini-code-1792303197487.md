# Clean Architecture Engineering Skill

Use this skill whenever designing, implementing, or refactoring backend services, APIs, or modular applications using Clean Architecture.

## 1. The Dependency Rule (Non-Negotiable)

Source code dependencies MUST point strictly inward toward the core business logic:
`Presentation (API/UI)` $\rightarrow$ `Infrastructure` $\rightarrow$ `Application` $\rightarrow$ `Domain`

1. **`Domain` Layer (Core Enterprise Logic — Zero External Dependencies):**
   - Contains **Entities**, **Value Objects**, **Domain Events**, **Enums**, and **Domain Exceptions**.
   - Entities must encapsulate state mutations via domain methods (Rich Domain Model, private setters) rather than anemic public getters/setters.
   - **Forbidden in Domain:** ORM attributes (`[Table]`, `[Key]`), JSON serialization attributes, HTTP types, or third-party SDK references.

2. **`Application` Layer (Use Cases & Orchestration):**
   - Depends ONLY on `Domain`.
   - Organizes business operations by feature using **CQRS** (`Commands` for state mutation, `Queries` for read-only projections).
   - Defines interfaces (`IRepository<T>`, `IUnitOfWork`, `ICurrentUserService`, `IEmailSender`) that `Infrastructure` must implement.
   - Uses **Result Pattern** (`Result<T>`) for expected business errors instead of throwing exceptions for control flow.

3. **`Infrastructure` Layer (External Concerns & Persistence):**
   - Implements interfaces defined in `Application`.
   - Contains EF Core `DbContext`, `IEntityTypeConfiguration<T>` (Fluent API instead of polluting Domain entities), external API clients, Redis caching, file storage, and identity providers.

4. **`Presentation / WebAPI` Layer (Entry Point & Transport):**
   - Thin Controllers or Minimal APIs: receives HTTP request $\rightarrow$ dispatches Command/Query $\rightarrow$ maps `Result<T>` to standard HTTP status codes (`200 OK`, `201 Created`, `400 Bad Request`, `404 Not Found`, `409 Conflict`).
   - Contains zero business logic or direct `DbContext` queries.

## 2. Reference Implementation Pattern (C# / .NET)

```csharp
// 1. DOMAIN LAYER: Rich Entity with Invariant Enforcement
namespace Project.Domain.Entities;

public sealed class StorageUnit : BaseAuditableEntity
{
    public string Code { get; private set; } = default!;
    public decimal AreaSqm { get; private set; }
    public UnitStatus Status { get; private set; }

    private StorageUnit() { } // For ORM

    public static Result<StorageUnit> Create(string code, decimal areaSqm)
    {
        if (string.IsNullOrWhiteSpace(code))
            return Error.Validation("StorageUnit.InvalidCode", "Unit code is required.");
        if (areaSqm <= 0)
            return Error.Validation("StorageUnit.InvalidArea", "Area must be greater than zero.");

        return new StorageUnit { Code = code.Trim().ToUpperInvariant(), AreaSqm = areaSqm, Status = UnitStatus.Available };
    }

    public Result Reserve()
    {
        if (Status != UnitStatus.Available)
            return Error.Conflict("StorageUnit.NotAvailable", $"Unit {Code} cannot be reserved in state {Status}.");

        Status = UnitStatus.Reserved;
        AddDomainEvent(new StorageUnitReservedEvent(Id, Code));
        return Result.Success();
    }
}

// 2. APPLICATION LAYER: Use-Case Handler (Decoupled from EF Core)
namespace Project.Application.StorageUnits.Commands.ReserveUnit;

public sealed record ReserveUnitCommand(Guid UnitId) : IRequest<Result>;

public sealed class ReserveUnitCommandHandler(
    IStorageUnitRepository repository,
    IUnitOfWork unitOfWork) : IRequestHandler<ReserveUnitCommand, Result>
{
    public async Task<Result> Handle(ReserveUnitCommand request, CancellationToken ct)
    {
        var unit = await repository.GetByIdAsync(request.UnitId, ct);
        if (unit is null)
            return Error.NotFound("StorageUnit.NotFound", "Storage unit not found.");

        var reserveResult = unit.Reserve();
        if (reserveResult.IsFailure)
            return reserveResult.Error;

        await unitOfWork.SaveChangesAsync(ct);
        return Result.Success();
    }
}
```
