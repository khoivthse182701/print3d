# Legacy schema references

Hai file `TheBoys_Schema_DDL.sql` và `TheBoys_EFCore_Configurations.cs` được giữ nguyên nội dung từ thư mục database cũ để truy vết. File C# ở đây không thuộc project build. Chúng **không phải** schema runtime hiện hành hoặc migration vNext. Không chạy DDL này lên DB đã được EF quản lý.
