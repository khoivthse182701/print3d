# Tài liệu lưu trữ

`ai-notes/` giữ nguyên ghi chú và prompt/tài liệu cũ từng ở `skills/`. Chúng không phải nguồn yêu cầu hoặc quy tắc runtime hiện hành. Tham khảo nội dung cần đối chiếu lại code/SRS. Không tự động coi một `SKILL.md` trong archive là hướng dẫn repository.

Các slide SWD của giảng viên chỉ được tham khảo từ máy người dùng, không sao chép vào repository này.
