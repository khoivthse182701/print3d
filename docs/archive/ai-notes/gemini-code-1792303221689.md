# Hardcode Detection & Decoupling Skill

Use this skill whenever the user asks to fix hardcoded values, externalize configurations, clean up magic numbers/strings, or prepare code for multi-environment deployment (`Dev`, `Staging`, `Prod`).

## 1. Classification & Extraction Rules

Scan the target file/project for these 5 categories of hardcoding and apply the exact extraction target:

| Hardcode Category | Examples Found in Code | Target Extraction Mechanism |
| :--- | :--- | :--- |
| **1. Secrets & Credentials** | API keys, JWT secrets, DB passwords, SMTP credentials | **Environment Variables (`.env` / User Secrets / Secret Manager)** — NEVER commit to `appsettings.json` or Git. |
| **2. Environment & Infrastructure** | Base URLs (`"https://api..."`), port numbers, file paths (`"C:\\temp\\..."`), timeouts (`30000`), retry counts | **Strongly-Typed Options (`IOptions<T>` / `appsettings.json` / `.env` config module)** + `Path.Combine()`. |
| **3. Mutable Business Thresholds** | Tax rate (`0.08m`), max upload size (`10485760`), discount tiers, pagination limits (`PageSize = 20`) | **Feature Options / Domain Policy Configuration (`PricingOptions`, `StoragePolicyOptions`)** or Database Settings table. |
| **4. Domain States & Type Codes** | Status strings (`"ACTIVE"`, `"PENDING"`), Role names (`"Admin"`), Role IDs (`if (roleId == 2)`) | **Strongly-Typed Enums, Smart Enums, or `static class DomainConstants / Roles`**. |
| **5. Magic Numbers in Physics / Math / UI** | Unexplained literals (`0.0167f`, `36.0`, `86400`, `#1E293B`) | **Named `const` / `readonly` Constants with Units in the Name** (e.g., `SecondsPerDay = 86_400`, `FullFrameSensorWidthMm = 36.0f`) or Theme Tokens. |

## 2. Refactoring Workflow

1. **Audit:** List every hardcoded literal found with its line number and category.
2. **Create Configuration / Constant Contract:**
   - Generate the strongly-typed Options class (with `[Required]` / `ValidateOnStart()` validation), Enum, or Constants file.
3. **Inject & Replace:**
   - Inject `IOptions<T>` (or import the config/constants module) into the consumer class and replace all inline literals.
4. **Sync Configuration Template:**
   - Output the corresponding `appsettings.json` / `.env.example` block so the project runs without missing keys.

## 3. Reference Refactoring Example

### Before (Hardcoded & Fragile)
```csharp
public async Task<string> UploadInvoiceAsync(IFormFile file, decimal subTotal)
{
    if (file.Length > 5242880) // Magic number: 5MB
        throw new Exception("File too large");

    var ext = Path.GetExtension(file.FileName);
    if (ext != ".pdf" && ext != ".png") // Magic strings
        throw new Exception("Invalid format");

    var totalWithVat = subTotal * 1.08m; // Hardcoded 8% VAT
    var savePath = "D:\\Uploads\\Invoices\\" + file.FileName; // Hardcoded OS path
    // ...
}
```

### After (Decoupled & Strongly-Typed)
```csharp
public sealed class InvoiceStorageOptions
{
    public const string SectionName = "InvoiceStorage";
    public long MaxFileSizeBytes { get; init; } = 5 * 1024 * 1024;
    public string[] AllowedExtensions { get; init; } = [".pdf", ".png"];
    public decimal VatMultiplier { get; init; } = 1.08m;
    public string RootUploadDirectory { get; init; } = "Uploads/Invoices";
}

public async Task<string> UploadInvoiceAsync(IFormFile file, decimal subTotal)
{
    if (file.Length > _options.MaxFileSizeBytes)
        throw new ValidationException($"File exceeds maximum limit of {_options.MaxFileSizeBytes} bytes.");

    var ext = Path.GetExtension(file.FileName).ToLowerInvariant();
    if (!_options.AllowedExtensions.Contains(ext))
        throw new ValidationException($"Unsupported file extension: {ext}");

    var totalWithVat = subTotal * _options.VatMultiplier;
    var safeFileName = Path.GetFileName(file.FileName);
    var savePath = Path.Combine(_options.RootUploadDirectory, safeFileName);
    // ...
}
```
