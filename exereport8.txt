1. TỔNG QUAN KIẾN TRÚC & MỤC TIÊU
--------------------------------------------------------------------------------
Hệ thống thanh toán của THE BOYS được thiết kế theo mô hình Gateway-Agnostic dựa trên
Clean Architecture. Tiếp nối SandboxPaymentGateway và SePayPaymentGateway, cổng thanh
toán PayOS (PayOSPaymentGateway) đã được thiết kế và tích hợp hoàn chỉnh vào tầng
Infrastructure (TheBoys.Infrastructure.Payments) và được đăng ký linh hoạt thông qua
PaymentGatewayRegistry.

Các mục tiêu cốt lõi đã đạt được:
1. Độc lập hạ tầng (Clean Architecture): Không can thiệp sửa đổi các domain invariants
   đã có; cắm PayOS vào interface IPaymentGateway chuẩn hóa.
2. Tính tất định & Hoạt động Offline 100% (Deterministic Offline Fallback):
   Khi ở chế độ kiểm thử (ClientId bắt đầu bằng "test-" hoặc rỗng), hệ thống tự động
   sinh VietQR checkout URL bằng cấu hình VietQrOptions sẵn có mà không phát sinh bất kỳ
   HTTP call nào ra internet, đảm bảo CI/CD và test suite chạy siêu tốc và ổn định.
3. Chuẩn hóa xác thực Webhook HMAC-SHA256 theo đặc tả PayOS:
   Thuật toán trích xuất object `data`, sắp xếp các khóa (keys) theo thứ tự bảng chữ
   cái (alphabetical order - StringComparer.Ordinal), định dạng chuỗi `key1=val1&key2=val2`,
   băm bằng HMAC-SHA256 với ChecksumKey và so sánh constant-time bằng FixedTimeEquals.
4. Xử lý thông minh Webhook Ping / Xác nhận kết nối từ Dashboard PayOS:
   Hỗ trợ tự động nhận diện gói tin ping thử nghiệm (orderCode: 123 hoặc description:
   "VQRIO123") từ my.payos.vn khi người quản trị bấm "Xác nhận Webhook", phản hồi HTTP
   200 OK với kết quả "WebhookTestAcknowledged" sạch sẽ, giải quyết triệt để nguy cơ
   báo lỗi 404/500 do thiếu PaymentAttempt trong database.
5. Bảo mật & Bất biến tài chính (Financial Invariants):
   - Ngăn chặn hoàn toàn timing attack nhờ CryptographicOperations.FixedTimeEquals.
   - Xử lý bất biến chênh lệch số tiền (Amount Mismatch) -> chuyển trạng thái đơn sang
     "NeedsAttention" và ghi nhận Outbox/Audit log.
   - Xử lý Webhook trùng lặp (Idempotent Deduplication) thông qua PaymentEvents inbox
     bằng EventId -> trả ACK ngay mà không sinh duplicate capture side-effects.

2. CHI TIẾT THAY ĐỔI & FILE MÃ NGUỒN
--------------------------------------------------------------------------------
A. Cấu hình hệ thống (Options Pattern):
   - File: src/TheBoys.Infrastructure/Payments/PaymentOptions.cs
     + Bổ sung class `PayOsOptions` chứa: ClientId, ApiKey, ChecksumKey, BaseUrl,
       ReturnUrl, CancelUrl, WebhookReplayWindowSeconds.
     + Thêm thuộc tính `PayOS` vào `PaymentOptions`.
   - File: src/TheBoys.WebApi/appsettings.json
     + Bổ sung section `"PayOS"` trong `"PaymentSettings"` với các giá trị cấu hình mẫu
       an toàn, không chứa secret thật.

B. Hợp đồng thanh toán (Payment Contracts):
   - File: src/TheBoys.Application/Common/Payments/PaymentContracts.cs
     + Mở rộng record `WebhookVerificationResult` thêm thuộc tính tùy chọn
       `bool IsTestWebhook = false` để truyền tải tín hiệu webhook ping thử nghiệm.

C. Hiện thực Gateway (PayOSPaymentGateway):
   - File: src/TheBoys.Infrastructure/Payments/PayOSPaymentGateway.cs
     + Implement `IPaymentGateway` với `GatewayName => "PayOS"`.
     + `IsConfigured`: Kiểm tra đủ bộ 3 (ClientId, ApiKey, ChecksumKey).
     + `CreateCheckoutAsync`: Hỗ trợ cả 2 chế độ:
       * Test mode (ClientId starts with "test-" or empty): Tự động sinh VietQR URL.
       * Live mode: Gửi POST /v2/payment-requests tới PayOS API với chữ ký HMAC-SHA256
         tính từ chuỗi amount={amount}&cancelUrl={cancelUrl}&description={description}&orderCode={orderCode}&returnUrl={returnUrl}.
     + `VerifyWebhookAsync`: Thuật toán xác minh chữ ký PayOS chuẩn hóa:
       * Parse JsonDocument, lấy `data` và `signature`.
       * Sắp xếp alphabet các properties của `data` và nối query string.
       * Tính HMAC-SHA256 với `ChecksumKey`.
       * So sánh FixedTimeEquals chống timing attack.
       * Nhận diện webhook ping test (orderCode == 123 hoặc description == "VQRIO123").
     + `GenerateOrderCode`: Thuật toán sinh mã orderCode kiểu số nguyên dương (dưới 2^53 - 1)
       một cách tất định (deterministic hashing) từ MerchantReference.
     + `QueryPaymentAsync`: Hỗ trợ tra cứu giao dịch (Offline trả QUERY_NOT_SUPPORTED_OFFLINE).
     + `SubmitRefundAsync` & `QueryRefundAsync`: Tuân thủ nguyên tắc fail-closed, trả
       NeedsAttention với mã "PayOsRefundNotSupported" do PayOS yêu cầu giải ngân ngân hàng.

D. Đăng ký Dependency Injection:
   - File: src/TheBoys.Infrastructure/DependencyInjection.cs
     + Đăng ký `services.AddHttpClient("PayOS");`.
     + Đăng ký `services.AddSingleton<IPaymentGateway, Payments.PayOSPaymentGateway>();`.
     + Tự động tích hợp vào `IPaymentGatewayRegistry` đa gateway.

E. Xử lý Webhook Ingress & Ping Handling:
   - File: src/TheBoys.Application/Payments/Commands/ProcessPaymentWebhook/ProcessPaymentWebhookCommandHandler.cs
     + Thêm logic kiểm tra: Nếu `attempt == null` nhưng `verification.IsTestWebhook` hoặc
       `verification.EventId == "123"` hoặc `verification.MerchantReference == "VQRIO123"`:
       -> Trả về Result.Success với Acknowledged: true và ProcessingResult: "WebhookTestAcknowledged".

F. Cấu hình Test Fixtures:
   - File: tests/TheBoys.Tests/Fixtures/DemoFactory.cs
     + Cung cấp cấu hình kiểm thử PayOS mặc định (test-client-id, test-api-key, test-checksum-key).
     + Vô hiệu hóa và loại bỏ `OutboxWorkerHostedService` trong test fixture để ngăn chặn
       race-condition ngoài ý muốn khi chạy song song 123 bài kiểm thử.
