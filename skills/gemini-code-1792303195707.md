# Smart & Concise Coding Skill

Use this skill whenever writing new logic or refactoring existing verbose code to maximize clarity, reduce cyclomatic complexity, and eliminate boilerplate.

## 1. Core Coding Principles (Strict Enforcement)

1. **Guard Clauses Over Arrow Anti-Pattern (Early Return):**
   - Never nest `if/else` blocks deeper than 2 levels. Validate edge cases at the very top of the method and return/throw immediately.
2. **Declarative & Functional Pipelines Over Imperative Loops:**
   - Replace manual `for/foreach` accumulator loops with LINQ (`.Where().Select().ToDictionary()`), JS/TS Array methods (`.filter().map().reduce()`), or Python list/dict comprehensions when side-effect free.
3. **Modern Language Idioms:**
   - **C# / .NET:** Use Primary Constructors, Collection Expressions (`[..]`), Switch Expressions, Pattern Matching (`is not null`, property patterns `{ Status: OrderStatus.Active }`), Null-coalescing assignment (`??=`), and `record` types for immutable DTOs.
   - **TypeScript / React:** Use optional chaining (`?.`), nullish coalescing (`??`), object destructuring, discriminated unions, and custom hooks to keep UI components stateless and compact.
   - **Python (`bpy` / Scripting):** Use generators, `next((x for x in items if cond), None)`, dataclasses, and context managers (`with`).
4. **Zero Redundant Boilerplate (YAGNI & DRY):**
   - Do not write pass-through wrapper methods that add zero logic.
   - Combine repetitive validation or mapping patterns into generic helper extensions or reusable expressions.

## 2. Transformation Examples

### Bad (Verbose, Deeply Nested, Imperative)
```csharp
public decimal CalculateDiscount(Customer customer, Order order)
{
    decimal discount = 0m;
    if (customer != null)
    {
        if (order != null && order.Items.Count > 0)
        {
            if (customer.IsVip && order.TotalAmount > 1000m)
            {
                discount = order.TotalAmount * 0.15m;
            }
            else if (!customer.IsVip && order.TotalAmount > 1000m)
            {
                discount = order.TotalAmount * 0.05m;
            }
        }
    }
    return discount;
}
```

### Good (Smart, Concise, Declarative Pattern Matching)
```csharp
public decimal CalculateDiscount(Customer? customer, Order? order) =>
    (customer, order) switch
    {
        (null, _) or (_, null) or (_, { Items.Count: 0 }) => 0m,
        ({ IsVip: true }, { TotalAmount: > 1000m } o) => o.TotalAmount * 0.15m,
        (_, { TotalAmount: > 1000m } o) => o.TotalAmount * 0.05m,
        _ => 0m
    };
```
