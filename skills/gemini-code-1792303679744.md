# Smooth-Scroll 3D & Parallax Web Architect Skill

Use this skill whenever the user asks to build a 3D animated website, scrollytelling landing page, multi-layer parallax experience (like the Nohosan VISITE/Tranquility/Biodiversity showcase), or scroll-driven WebGL 3D camera journey.

---

## 1. Mandatory 5-Pillar Architecture for Buttery-Smooth 60–120 FPS Scroll

Never bind raw `window.addEventListener('scroll')` to modify DOM layout properties (`top`, `left`, `width`, `height`). Every 3D scroll website MUST implement these 5 architectural layers:

### Pillar 1: Inertial Smooth Scroll Engine (`Lenis` + `GSAP Ticker` Sync)
- Always initialize **Lenis** (`lerp: 0.07`, `smoothWheel: true`) and synchronize it directly with `gsap.ticker` and `ScrollTrigger.update` so scroll physics and animations share the exact same `requestAnimationFrame` tick with zero frame jitter.

### Pillar 2: Multi-Plane Z-Depth Composition (5-to-7 Layer Rule)
Every storytelling scene must be decomposed into distinct depth planes along the Z-axis:
1. **`L0_Sky_Backdrop` (`z: -300px`, speed `0.15x`):** Distant sky, gradients, stars, or mountain silhouettes.
2. **`L1_Far_Environment` (`z: -150px`, speed `0.35x`):** Distant cliffs, clouds, waterfalls.
3. **`L2_Mid_Atmosphere` (`z: -60px`, speed `0.65x`):** Animated birds, mist, floating particles, water ripples.
4. **`L3_Hero_Subject` (`z: 0px`, speed `1.0x`):** Primary focal character/subject (traveler, angler, deer, 3D model) + Editorial Typography.
5. **`L4_Foreground_Blocker_Mask` (`z: +120px`, speed `1.8x`):** Dark cliff edges, foliage silhouettes, or rock arches that sweep across the viewport during scroll to seamlessly mask the transition into the next scene.

### Pillar 3: Master Pinned Timeline & Seamless Scene Transitions (`GSAP ScrollTrigger`)
- Pin a single full-screen viewport stage (`100vw x 100vh`, `overflow: hidden`, `perspective: 1200px`) for `400%–600%` of viewport scroll height (`end: "+=450%"`, `scrub: 1.2`).
- Transition between scenes (`Scene 01 -> Scene 02 -> Scene 03`) using **3D Camera Panning** (translating the entire world container along `X`, `Y`, `Z` and `scale`) while sweeping a `Foreground_Blocker_Mask` across the screen to hide layer swaps.

### Pillar 4: Dual-Input Camera Rig (Scroll Progress + Mouse Cursor Lerp)
- Combine **Macro Movement** (driven by ScrollTrigger timeline) with **Micro Movement** (driven by normalized mouse coordinates `[-0.5, 0.5]` smoothed via `gsap.quickTo` or `THREE.MathUtils.damp`).
- Deeper layers move less on mouse hover; foreground layers shift more, creating an instant 3D holographic window effect even when the user stops scrolling.

### Pillar 5: GPU Compositing & Cleanup Discipline
- Apply `will-change: transform, opacity` and `transform: translate3d(0,0,0)` to all moving layers.
- Wrap all GSAP animations inside `gsap.context()` (or `useGSAP()`) and revert them cleanly on component unmount.

## 2. Reference Implementation A: Multi-Plane 3D Parallax Storytelling (React + TypeScript + GSAP + Lenis)

Use this template for 2.5D/3D layered illustration & editorial storytelling websites (exact Nohosan `VISITE -> Tranquility -> Biodiversity` architecture):

```tsx
import React, { useEffect, useRef } from 'react';
import gsap from 'gsap';
import { ScrollTrigger } from 'gsap/ScrollTrigger';
import Lenis from 'lenis';

gsap.registerPlugin(ScrollTrigger);

export const SmoothScroll3DShowcase: React.FC = () => {
  const rootRef = useRef<HTMLDivElement>(null);
  const viewportRef = useRef<HTMLDivElement>(null);
  const worldCameraRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    // 1. Initialize Lenis Inertial Smooth Scroll synced with GSAP Ticker
    const lenis = new Lenis({
      lerp: 0.07,
      smoothWheel: true,
      wheelMultiplier: 0.9,
    });

    lenis.on('scroll', ScrollTrigger.update);
    const updateLenis = (time: number) => lenis.raf(time * 1000);
    gsap.ticker.add(updateLenis);
    gsap.ticker.lagSmoothing(0);

    // 2. Build Master 3D Scroll Timeline inside gsap.context
    const ctx = gsap.context(() => {
      const tl = gsap.timeline({
        scrollTrigger: {
          trigger: viewportRef.current,
          start: 'top top',
          end: '+=450%', // 4.5x screen height scroll journey
          pin: true,
          scrub: 1.2,    // Smooth 1.2s catch-up inertia
          anticipatePin: 1,
        },
      });

      // --- TRANSITION 1: Scene 1 (VISITE Peak) -> Scene 2 (Tranquility Waterfall) ---
      tl.to('.scene-1-ui', { yPercent: -60, autoAlpha: 0, duration: 1.2, ease: 'power2.inOut' }, 0)
        .to('.layer-sky', { yPercent: -12, scale: 1.08, duration: 2, ease: 'none' }, 0)
        .to('.layer-far-mountain', { yPercent: -28, scale: 1.15, duration: 2, ease: 'power1.inOut' }, 0)
        .to('.layer-hero-traveler', { yPercent: -85, xPercent: 15, scale: 1.35, autoAlpha: 0, duration: 1.6, ease: 'power2.in' }, 0)
        // Foreground rock cliff sweeps up across camera to mask transition
        .fromTo('.mask-cliff-bridge-1',
          { yPercent: 100, scale: 1.2 },
          { yPercent: -110, scale: 1.0, duration: 2.0, ease: 'power1.inOut' },
          0.1
        )
        // Reveal Scene 2 (Tranquility Waterfall & Angler)
        .fromTo('.scene-2-world',
          { yPercent: 75, scale: 0.88, autoAlpha: 0 },
          { yPercent: 0, scale: 1.0, autoAlpha: 1, duration: 1.8, ease: 'power2.out' },
          0.6
        )
        .fromTo('.scene-2-ui',
          { y: 60, autoAlpha: 0 },
          { y: 0, autoAlpha: 1, duration: 1.0, ease: 'power3.out' },
          1.2
        )
        .fromTo('.scene-2-birds',
          { xPercent: -30, yPercent: 20, scale: 0.7 },
          { xPercent: 25, yPercent: -15, scale: 1.1, duration: 2.2, ease: 'none' },
          0.7
        );

      // --- TRANSITION 2: Scene 2 (Tranquility) -> Scene 3 (Biodiversity Deer Forest) ---
      tl.to('.scene-2-ui', { xPercent: -40, autoAlpha: 0, duration: 1.0, ease: 'power2.in' }, 2.4)
        .to('.scene-2-world', { xPercent: -35, yPercent: -45, scale: 1.25, autoAlpha: 0, duration: 1.8, ease: 'power2.inOut' }, 2.4)
        // Diagonal foliage & rock curtain wipe
        .fromTo('.mask-foliage-bridge-2',
          { xPercent: 100, yPercent: 60, scale: 1.3 },
          { xPercent: -110, yPercent: -60, scale: 1.0, duration: 2.0, ease: 'power1.inOut' },
          2.3
        )
        // Enter Scene 3 (Biodiversity Deer Sanctuary)
        .fromTo('.scene-3-world',
          { xPercent: 35, yPercent: 40, scale: 0.85, autoAlpha: 0 },
          { xPercent: 0, yPercent: 0, scale: 1.0, autoAlpha: 1, duration: 1.8, ease: 'power2.out' },
          2.7
        )
        .fromTo('.scene-3-ui',
          { y: 50, autoAlpha: 0 },
          { y: 0, autoAlpha: 1, duration: 1.1, ease: 'power3.out' },
          3.3
        );
    }, rootRef);

    // 3. Interactive Mouse Cursor 3D Tilt & Depth Offset (gsap.quickTo)
    const rotX = gsap.quickTo(worldCameraRef.current, 'rotationX', { duration: 0.8, ease: 'power3.out' });
    const rotY = gsap.quickTo(worldCameraRef.current, 'rotationY', { duration: 0.8, ease: 'power3.out' });
    const moveFgX = gsap.quickTo('.parallax-fg', 'x', { duration: 0.6, ease: 'power2.out' });
    const moveFgY = gsap.quickTo('.parallax-fg', 'y', { duration: 0.6, ease: 'power2.out' });

    const handleMouseMove = (e: MouseEvent) => {
      const nx = (e.clientX / window.innerWidth - 0.5) * 2;  // [-1, 1]
      const ny = (e.clientY / window.innerHeight - 0.5) * 2; // [-1, 1]
      rotY(nx * 3.5);
      rotX(-ny * 2.5);
      moveFgX(-nx * 28);
      moveFgY(-ny * 18);
    };

    window.addEventListener('mousemove', handleMouseMove, { passive: true });

    return () => {
      window.removeEventListener('mousemove', handleMouseMove);
      ctx.revert();
      gsap.ticker.remove(updateLenis);
      lenis.destroy();
    };
  }, []);

  return (
    <div ref={rootRef} className="bg-[#0b0d19] text-slate-100 select-none">
      {/* Fixed Top Navigation */}
      <header className="fixed top-0 inset-x-0 z-50 flex items-center justify-between px-12 py-6 backdrop-blur-sm bg-slate-950/20">
        <span className="text-lg font-semibold tracking-wider text-amber-100">Nohosan</span>
        <nav className="hidden md:flex items-center gap-10 text-sm text-slate-300">
          <a href="#community" className="hover:text-white transition">Community</a>
          <a href="#about" className="hover:text-white transition">About</a>
          <a href="#support" className="hover:text-white transition">Support</a>
          <a href="#contact" className="hover:text-white transition">Contact</a>
        </nav>
        <button className="px-5 py-2 rounded-full border border-slate-400/40 text-xs uppercase tracking-widest hover:bg-white hover:text-slate-950 transition">
          Register
        </button>
      </header>

      {/* Pinned 3D Viewport Stage */}
      <section
        ref={viewportRef}
        className="relative w-screen h-screen overflow-hidden"
        style={{ perspective: '1200px' }}
      >
        <div
          ref={worldCameraRef}
          className="relative w-full h-full will-change-transform"
          style={{ transformStyle: 'preserve-3d' }}
        >
          {/* GLOBAL SKY & FAR MOUNTAINS */}
          <div className="layer-sky absolute inset-[-8%] bg-gradient-to-b from-[#1e1b38] via-[#4a3556] to-[#121629] will-change-transform" />
          <div className="layer-far-mountain absolute inset-0 bg-[radial-gradient(circle_at_70%_35%,rgba(245,158,11,0.35),transparent_55%)] will-change-transform" />

          {/* ================= SCENE 1: VISITE (PEAK) ================= */}
          <div className="scene-1-ui absolute inset-0 z-20 flex flex-col justify-center px-12 md:px-24 max-w-3xl">
            <p className="text-xs uppercase tracking-[0.3em] text-amber-200/80 mb-3">
              Journey to Noh&apos;s Natural Park
            </p>
            <h1 className="text-7xl md:text-9xl font-serif font-bold tracking-tight text-white drop-shadow-lg">
              VISITE
            </h1>
            <p className="mt-6 text-sm md:text-base text-slate-200/90 leading-relaxed max-w-md">
              Away from the crazy energy of Japan&apos;s famous metropolises lies the ancient hamlet of Noh,
              bordered by crystal waters and timeless mountain peaks.
            </p>
            <button className="mt-8 w-fit px-6 py-3 rounded-lg bg-white text-slate-950 text-xs font-semibold tracking-wider flex items-center gap-3 shadow-xl">
              Start the journey <span>→</span>
            </button>
          </div>

          <div className="layer-hero-traveler parallax-fg absolute right-[6%] bottom-[-4%] w-[42vw] max-w-[560px] aspect-square z-30 will-change-transform pointer-events-none">
            {/* Replace with transparent PNG/WebP or SVG of Traveler on Grassy Cliff */}
            <div className="w-full h-full rounded-t-full bg-gradient-to-t from-[#090d1a] via-[#2b1e38] to-amber-500/30 border-t border-amber-300/30 shadow-2xl" />
          </div>

          {/* FOREGROUND BRIDGE MASK 1 (Sweeps across screen between Scene 1 & 2) */}
          <div className="mask-cliff-bridge-1 absolute inset-x-[-10%] bottom-[-20%] h-[65vh] bg-gradient-to-t from-[#070a14] via-[#10172a] to-transparent z-40 pointer-events-none will-change-transform" />

          {/* ================= SCENE 2: TRANQUILITY (WATERFALL) ================= */}
          <div className="scene-2-world absolute inset-0 z-20 opacity-0 will-change-transform">
            {/* Animated Waterfall Column */}
            <div className="absolute left-[12%] inset-y-0 w-[18vw] bg-gradient-to-b from-cyan-200/60 via-sky-400/40 to-indigo-950/80 blur-[1px]" />
            <div className="scene-2-birds parallax-fg absolute left-[38%] top-[36%] text-white/90 text-2xl tracking-[1em]">
              🕊️ 🕊️
            </div>
            <div className="scene-2-ui absolute right-[10%] top-[26%] max-w-md">
              <span className="text-xs uppercase tracking-[0.25em] text-cyan-300/80">01 / Sanctuary</span>
              <h2 className="mt-2 text-5xl md:text-6xl font-serif font-semibold text-white">
                Tranquility
              </h2>
              <p className="mt-4 text-sm text-slate-300 leading-relaxed">
                Cascading mountain waters carve serene emerald pools where time slows down amidst ancient moss-covered stones.
              </p>
            </div>
          </div>

          {/* FOREGROUND BRIDGE MASK 2 (Diagonal Wipe between Scene 2 & 3) */}
          <div className="mask-foliage-bridge-2 absolute inset-[-15%] bg-gradient-to-tr from-[#060913] via-[#131b33] to-transparent z-40 pointer-events-none will-change-transform" />

          {/* ================= SCENE 3: BIODIVERSITY (FOREST DEER) ================= */}
          <div className="scene-3-world absolute inset-0 z-20 opacity-0 will-change-transform">
            <div className="scene-3-ui absolute left-[10%] top-[30%] max-w-md">
              <span className="text-xs uppercase tracking-[0.25em] text-emerald-300/80">02 / Ecosystem</span>
              <h2 className="mt-2 text-5xl md:text-6xl font-serif font-semibold text-white">
                Biodiversity
              </h2>
              <p className="mt-4 text-sm text-slate-300 leading-relaxed">
                Home to sacred spotted deer and bioluminescent alpine flora thriving in untouched harmony.
              </p>
            </div>
          </div>
        </div>
      </section>
    </div>
  );
};
```

## 3. Reference Implementation B: True 3D WebGL Camera Spline Rig (`@react-three/fiber` + `Three.js`)

When the project uses real `.glb` 3D environments instead of 2D/2.5D layered artwork, drive the PerspectiveCamera along a smooth 3D `CatmullRomCurve3` using `@react-three/drei`'s `ScrollControls` and frame-rate-independent damping (`THREE.MathUtils.damp`):

```tsx
import React, { useMemo, useRef } from 'react';
import * as THREE from 'three';
import { Canvas, useFrame } from '@react-three/fiber';
import { ScrollControls, useScroll, Environment, Float } from '@react-three/drei';

const CameraScrollSplineRig: React.FC = () => {
  const scroll = useScroll();
  const lookAtTarget = useRef(new THREE.Vector3(0, 2, 0));

  // Define 3D Camera Waypoints (Scene 1 Peak -> Scene 2 Waterfall -> Scene 3 Forest)
  const { cameraCurve, targetCurve } = useMemo(() => {
    const cameraCurve = new THREE.CatmullRomCurve3([
      new THREE.Vector3(0, 6, 14),   // Scene 1: High mountain vista
      new THREE.Vector3(-4, 3, 6),   // Scene 2: Mid-cliff waterfall plunge
      new THREE.Vector3(3, 1.2, -4), // Scene 3: Low forest clearing
    ]);
    const targetCurve = new THREE.CatmullRomCurve3([
      new THREE.Vector3(0, 4, 0),
      new THREE.Vector3(-2, 2, -2),
      new THREE.Vector3(0, 1, -10),
    ]);
    return { cameraCurve, targetCurve };
  }, []);

  useFrame((state, delta) => {
    // 1. Sample spline position from normalized scroll offset [0..1]
    const t = THREE.MathUtils.clamp(scroll.offset, 0, 1);
    const desiredCamPos = cameraCurve.getPointAt(t);
    const desiredLookAt = targetCurve.getPointAt(t);

    // 2. Add subtle mouse-move parallax offset (pointer.x, pointer.y in [-1, 1])
    desiredCamPos.x += state.pointer.x * 0.65;
    desiredCamPos.y += state.pointer.y * 0.45;

    // 3. Frame-rate independent smooth damping (butter-smooth camera inertia)
    state.camera.position.x = THREE.MathUtils.damp(state.camera.position.x, desiredCamPos.x, 4.5, delta);
    state.camera.position.y = THREE.MathUtils.damp(state.camera.position.y, desiredCamPos.y, 4.5, delta);
    state.camera.position.z = THREE.MathUtils.damp(state.camera.position.z, desiredCamPos.z, 4.5, delta);

    lookAtTarget.current.x = THREE.MathUtils.damp(lookAtTarget.current.x, desiredLookAt.x, 5.0, delta);
    lookAtTarget.current.y = THREE.MathUtils.damp(lookAtTarget.current.y, desiredLookAt.y, 5.0, delta);
    lookAtTarget.current.z = THREE.MathUtils.damp(lookAtTarget.current.z, desiredLookAt.z, 5.0, delta);

    state.camera.lookAt(lookAtTarget.current);
  });

  return null;
};

export const True3DScrollWebsite: React.FC = () => (
  <div className="w-screen h-screen bg-[#070a14]">
    <Canvas 14], 2]} 42 6, [0, camera="{{" dpr="{[1," fov: position: }}>
      <fog attach="fog" args={['#070a14', 6, 28]} />
      <Environment preset="sunset"/>
      <ScrollControls damping="{0.18}" pages="{4}">
        <CameraScrollSplineRig/>
        <Float floatIntensity="{0.5}" rotationIntensity="{0.2}" speed="{1.4}">
          {/* Mount GLTF/GLB 3D Environment Models Here */}
          <mesh position={[0, 1, -2]}>
            <icosahedronGeometry args={[1.5, 1]} />
            <meshStandardMaterial color="#d4af37" roughness={0.3} metalness={0.7} />
          </mesh>
        </Float>
      </ScrollControls>
    </Canvas>
  </div>
);
```

## 4. Quality Verification Checklist Before Delivery

1. **Zero Scrollbar Jump:** Confirm `ScrollTrigger` pinning does not cause horizontal overflow (`overflow-x: hidden` on `body`).
2. **Reversible Scrubbing:** Scroll rapidly from top to bottom and back from bottom to top — all text blocks, masks, and 3D layers must reverse cleanly without getting stuck in `opacity: 0`.
3. **Asset Layering Guide:** If the user does not yet have separated layer PNGs/WebPs or `.glb` models, automatically generate placeholder SVG/CSS depth layers with clear comments indicating where to swap in `foreground-cliff.webp`, `mid-waterfall.webp`, and `background-mountain.webp`.
