# System & Developer Storage Cleaner Skill

Use this skill whenever the user asks to free up disk space, analyze why a drive (`C:`, `D:`, `/`) is full, clean temporary/cache files, or purge heavy build artifacts across development and 3D projects.

---

## 1. Mandatory 4-Step Safety Protocol (Zero Data Loss Guarantee)

Never execute destructive deletion (`Remove-Item -Recurse -Force` or `rm -rf`) blindly. You MUST follow this exact sequence:

1. **Step 1 — Baseline Disk Snapshot & Dry-Run Audit:**
   - Measure current free/used space on target drives.
   - Scan and calculate the exact size (in MB/GB) of each cleanup category **without deleting anything**.
2. **Step 2 — Risk Classification Matrix:**
   Group discovered items into 3 strict tiers:
   - 🟢 **Tier 1: 100% Safe Auto-Purge (Temp & System Caches):** OS `%TEMP%`, browser crash dumps, package manager download caches (`npm cache`, `pip cache`, `NuGet http-cache`), thumbnail caches.
   - 🟡 **Tier 2: Regenerable Project Build Artifacts (Safe if project is not currently building/running):**
     - **Web / Node.js:** `node_modules`, `.next`, `dist`, `build`, `.turbo`.
     - **.NET / C#:** `bin`, `obj`, `TestResults`.
     - **Unity Engine:** `Library`, `Temp`, `Obj`, `Logs`, `MemoryCaptures`.
     - **Blender 3D:** `blendcache_*` (baked physics/cloth/fluid caches), `.blend1` / `.blend2` auto-backup files, `/tmp` render frames.
     - **Python:** `__pycache__`, `.pytest_cache`, `.mypy_cache`.
   - 🔴 **Tier 3: High-Sensitivity (Requires Explicit User Confirmation):** `Downloads` folder, Recycle Bin / Trash, Docker unused images/volumes (`docker system prune`), WSL2 virtual disk compaction (`ext4.vhdx`), local `.env` or database `.mdf`/`.ldf`/`.sqlite` files.
3. **Step 3 — Targeted Execution:**
   - Skip locked files silently (`-ErrorAction SilentlyContinue`) so active processes do not crash the cleanup script.
   - Never touch source code files (`.cs`, `.ts`, `.tsx`, `.py`, `.blend`, `.unity`, `.prefab`, `.sln`, `.csproj`, `package.json`).
4. **Step 4 — Post-Cleanup Verification Report:**
   - Re-measure drive free space and output a clear **Before vs. After** table showing exact GBs reclaimed.

## 2. Reference PowerShell Implementation (Windows — Audit & Cleanup)

Use these modular PowerShell functions to audit and clean Windows systems and project workspaces:

```powershell
# ============================================================================
# 1. HELPER: Measure Folder Size Safely (in MB)
# ============================================================================
function Get-FolderSizeMB {
    param([string]$Path)
    if (-not (Test-Path -LiteralPath $Path)) { return 0 }
    $bytes = (Get-ChildItem -LiteralPath $Path -Recurse -Force -File -ErrorAction SilentlyContinue |
              Measure-Object -Property Length -Sum).Sum
    if (-not $bytes) { return 0 }
    return [math]::Round($bytes / 1MB, 2)
}

# ============================================================================
# 2. STEP 1: NON-DESTRUCTIVE DISK & CACHE AUDIT
# ============================================================================
function Invoke-StorageAudit {
    param([string]$WorkspaceRoot = "$HOME\source")

    Write-Host "=== 1. DRIVE SPACE SNAPSHOT ===" -ForegroundColor Cyan
    Get-PSDrive -PSProvider FileSystem | Where-Object { $_.Used -gt 0 } | ForEach-Object {
        $usedGB = [math]::Round($_.Used / 1GB, 2)
        $freeGB = [math]::Round($_.Free / 1GB, 2)
        $totalGB = [math]::Round(($_.Used + $_.Free) / 1GB, 2)
        Write-Host ("Drive {0}: {1} GB Free / {2} GB Total (Used: {3} GB)" -f $_.Name, $freeGB, $totalGB, $usedGB)
    }

    Write-Host "`n=== 2. SYSTEM & DEV CACHE AUDIT (TIER 1) ===" -ForegroundColor Cyan
    $targets = [ordered]@{
        "User Temp (%TEMP%)"          = $env:TEMP
        "Windows Temp"                = "C:\Windows\Temp"
        "NuGet Global Packages"       = "$HOME\.nuget\packages"
        "NuGet HTTP/Temp Cache"       = "$env:LOCALAPPDATA\NuGet\v3-cache"
        "NPM Cache"                   = "$env:LOCALAPPDATA\npm-cache"
        "PNPM Store"                  = "$env:LOCALAPPDATA\pnpm\store"
        "Pip Cache"                   = "$env:LOCALAPPDATA\pip\Cache"
        "Unity Asset Store Cache"     = "$env:APPDATA\Unity\Asset Store-5.x"
        "Unity Package Manager Cache" = "$env:LOCALAPPDATA\Unity\cache"
        "CrashDumps"                  = "$env:LOCALAPPDATA\CrashDumps"
    }

    $auditResults = foreach ($key in $targets.Keys) {$p = $targets[$key]
        if (Test-Path -LiteralPath $p) {
            [PSCustomObject]@{
                Category = $key
                Path     = $p
                SizeMB   = Get-FolderSizeMB -Path $p
            }
        }
    }
    $auditResults | Sort-Object SizeMB -Descending | Format-Table -AutoSize

    if (Test-Path -LiteralPath $WorkspaceRoot) {
        Write-Host "`n=== 3. WORKSPACE BUILD ARTIFACTS AUDIT (TIER 2): $WorkspaceRoot ===" -ForegroundColor Cyan
        $artifactDirs = Get-ChildItem -Path $WorkspaceRoot -Directory -Recurse -Force -ErrorAction SilentlyContinue |
            Where-Object { $_.Name -in @('node_modules', 'bin', 'obj', 'Library', 'Temp', '__pycache__') -or $_.Name -like 'blendcache_*' } |
            Where-Object { $_.FullName -notmatch '\\node_modules\\.*\\node_modules' }

        $artifactDirs | ForEach-Object {
            [PSCustomObject]@{
                Type   = $_.Name
                SizeMB = Get-FolderSizeMB -Path $_.FullName
                Path   = $_.FullName
            }
        } | Sort-Object SizeMB -Descending | Select-Object -First 25 | Format-Table -AutoSize
    }
}

# ============================================================================
# 3. STEP 2: SAFE EXECUTION CLEANUP PIPELINE
# ============================================================================
function Invoke-SafeStorageCleanup {
    param(
        [string]$WorkspaceRoot = "",
        [switch]$CleanTempAndCaches = $true,
        [switch]$CleanDotNetBinObj = $false,
        [switch]$CleanNodeModules = $false,
        [switch]$CleanUnityCaches = $false,
        [switch]$CleanBlenderCaches = $false
    )

    $driveBefore = (Get-PSDrive C).Free

    if ($CleanTempAndCaches) {
        Write-Host "[Tier 1] Cleaning OS Temp & Package Caches..." -ForegroundColor Yellow
        Remove-Item -Path "$env:TEMP\*" -Recurse -Force -ErrorAction SilentlyContinue
        Remove-Item -Path "C:\Windows\Temp\*" -Recurse -Force -ErrorAction SilentlyContinue
        Remove-Item -Path "$env:LOCALAPPDATA\CrashDumps\*" -Recurse -Force -ErrorAction SilentlyContinue

        # Native CLI Cache Cleaners (Safe & Official)
        if (Get-Command dotnet -ErrorAction SilentlyContinue) {
            dotnet nuget locals http-cache --clear | Out-Null
            dotnet nuget locals temp --clear | Out-Null
        }
        if (Get-Command npm -ErrorAction SilentlyContinue) {
            npm cache clean --force 2>$null | Out-Null
        }
        if (Get-Command pip -ErrorAction SilentlyContinue) {
            pip cache purge 2>$null | Out-Null
        }
    }

    if ($WorkspaceRoot -and (Test-Path -LiteralPath $WorkspaceRoot)) {
        if ($CleanDotNetBinObj) {
            Write-Host "[Tier 2] Cleaning .NET 'bin' and 'obj' folders in $WorkspaceRoot..." -ForegroundColor Yellow
            Get-ChildItem -Path $WorkspaceRoot -Include bin, obj -Directory -Recurse -Force -ErrorAction SilentlyContinue |
                Where-Object { $_.FullName -notmatch '\\node_modules\\' } |
                ForEach-Object { Remove-Item -LiteralPath $_.FullName -Recurse -Force -ErrorAction SilentlyContinue }
        }

        if ($CleanNodeModules) {
            Write-Host "[Tier 2] Cleaning 'node_modules' folders in $WorkspaceRoot..." -ForegroundColor Yellow
            Get-ChildItem -Path $WorkspaceRoot -Filter "node_modules" -Directory -Recurse -Force -ErrorAction SilentlyContinue |
                Where-Object { $_.FullName -notmatch '\\node_modules\\.*\\node_modules' } |
                ForEach-Object { Remove-Item -LiteralPath $_.FullName -Recurse -Force -ErrorAction SilentlyContinue }
        }

        if ($CleanUnityCaches) {
            Write-Host "[Tier 2] Cleaning Unity 'Library', 'Temp', and 'Logs' in $WorkspaceRoot..." -ForegroundColor Yellow
            Get-ChildItem -Path $WorkspaceRoot -Filter "ProjectVersion.txt" -Recurse -File -ErrorAction SilentlyContinue |
                ForEach-Object {
                    $unityRoot = $_.Directory.Parent.FullName
                    foreach ($sub in @('Library', 'Temp', 'Obj', 'Logs')) {
                        $target = Join-Path $unityRoot $sub
                        if (Test-Path -LiteralPath $target) {
                            Remove-Item -LiteralPath $target -Recurse -Force -ErrorAction SilentlyContinue
                        }
                    }
                }
        }

        if ($CleanBlenderCaches) {
            Write-Host "[Tier 2] Cleaning Blender 'blendcache_*' and '.blend1/.blend2' backups in $WorkspaceRoot..." -ForegroundColor Yellow
            Get-ChildItem -Path $WorkspaceRoot -Filter "blendcache_*" -Directory -Recurse -Force -ErrorAction SilentlyContinue |
                ForEach-Object { Remove-Item -LiteralPath $_.FullName -Recurse -Force -ErrorAction SilentlyContinue }
            Get-ChildItem -Path $WorkspaceRoot -Include *.blend1, *.blend2 -File -Recurse -Force -ErrorAction SilentlyContinue |
                ForEach-Object { Remove-Item -LiteralPath $_.FullName -Force -ErrorAction SilentlyContinue }
        }
    }

    $driveAfter = (Get-PSDrive C).Free
    $reclaimedGB = [math]::Round(($driveAfter - $driveBefore) / 1GB, 2)
    Write-Host ("`nDONE! Reclaimed approximately {0} GB on Drive C:." -f $reclaimedGB) -ForegroundColor Green
}
```

## 3. Reference Bash Implementation (macOS / Linux)

When running on macOS or Linux, use these safe audit and cleanup commands:

```bash
# 1. Audit Top 15 Largest Directories & Caches
df -h
du -sh ~/.cache ~/.npm ~/.nuget/packages ~/Library/Caches /tmp 2>/dev/null | sort -hr

# 2. Find Heavy Project Build Artifacts (Dry-Run List)
find ~/Projects -type d \( -name "node_modules" -o -name "bin" -o -name "obj" -o -name "Library" -o -name "blendcache_*" \) -prune -exec du -sh {} + 2>/dev/null | sort -hr | head -n 25

# 3. Clean Package Manager & Temp Caches Safely
npm cache clean --force 2>/dev/null
dotnet nuget locals http-cache --clear 2>/dev/null
pip cache purge 2>/dev/null
```
